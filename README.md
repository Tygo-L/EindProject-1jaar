# EindProject-1jaar
Web Rookie eindproject


de website staat online op de url :
https://groovespinners.netlify.app


Informatie over het project zelf:
ik was van plan om een vinyl webshop te maken. dus nu heb ik een leuke mooie en functionele website waar je bestellingen kan plaatsen en historische lp's kan vinden als admin kan je platen verwijderen toevoegen en aanpassen.

als je de website op een live server wilt bekijken kan je de repo clonen en in de terminal doen om de code te krijgen.
als je naar de admin page wilt gaan hoef je alleen admin of admin.html achter de url te zetten als volgt(https://groovespinners.netlify.app/admin.html) het werkt het zelfde met de live server.
